# Idea Pebble

A small, calm, static website for collecting curious questions and saving the ones worth keeping. It works without an account, backend, build step, external asset, or tracking. Saved thoughts stay in the current browser's local storage.

## Run it

Open `index.html` in a browser, or serve this directory with any static web server. The page makes no network requests.

## Files

- `index.html` — accessible page structure and project description
- `style.css` — responsive garden palette and card layout
- `app.js` — prompt picker and local notebook
